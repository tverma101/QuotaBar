## Visual contract

- **Surface/type:** system font, weights, rounded/monospaced-digit variants and semantic colors; meter blue/yellow/red, notice orange, positive green. `Support/Theme` defines tray/card fills and 12 pt card radius. `App/StatusItemController` uses a 13 pt panel radius. `Stores/DensitySetting` defines Default/Compact pairs: header 14/13 pt, supporting 12/11, badge 11/10, mark 16/14, meter 5/4, sparkline 18/14; bar row padding 10/5, text 6/4 (consecutive top 2/1), inner 4/3, sections 14/8, header gap 4/2, gutters 5/3, control rows 9/6, content top 14/10, link gap 6/4. Width does not change with density. Use view sources in the table as authority for inline spacing, borders, fonts, icon names and other per-control tokens; capture both macOS 15 fallback and 26 glass.
- **Chrome/motion:** `Support/{Animations,LiquidGlassFallbacks,PopoverSurfaceTreatment,PartyMode,TooMuchTransparencyEffect}`: spring response 0.42/damping 0.80; screen switch 0.18 s ease-in-out; opacity/effect changes, slide, resize, drag lift/snap and settle, disclosure, hover and feedback, loading spin, and decorative continuous effects. Respect reduced motion/contrast/transparency, stop effect work when hidden; preserve static fallback. `Views/AccountNameText` uses 0.15 s reveal; `Views/RateLimitResetsDetail` uses 0.25 s snappy flow; `Views/PopoverFooter` has 12 pt vertical padding. `Views/HeaderView` uses a 28 pt Options capsule, 13 pt semibold label and 11 pt chevron, 5 pt gap, leading/trailing padding 14/12 pt. macOS 26 glass lenses in-app scroll content; the translucent desktop backdrop is a different layer.
- **Marks/charts:** [ProviderIcons](../../Sources/QuotaBar/Resources/ProviderIcons), `Support/{ProviderIconShape,MenuBarIcon}`, `Views/{TotalSpendPalette,RingSectorShape,TotalSpendCard,UsageSparkline}`: original vectors, fallback symbols and fixed brand palette; Total Spend ring diameter 104 pt and minimum share 2.5%; rounded center numeral 13 pt and unit 9 pt. Preserve directional geometry, track/fill contrast, hover labels and sample selection (including empty/partial).
- **Strip:** `Models/MenuBarContent`, `App/StatusItemImageUpdater`, `Support/MenuBarStripRenderer`: one variable-width alpha-trimmed, backing-scale bitmap, template foreground tint, memoized by visible content/style/scale. Wordmark fallback/privacy state uses 16 pt mark/12 pt bold, 5 pt gap; metrics use 12 pt glyph, 9 pt semibold, stacked at −2 pt spacing; gaps 8 between providers and 3 within. Rounded Bars show up to four eligible fractions per provider, use 8% inset, 3% gap, at least two rows' sizing, 16% black track and 24% remainder with separator. Maintain stable footprint for special Freebuff countdown pairing and the all/snoozed/no-data fallback. [Menu bar behavior](../menu-bar.md).

## Background and persistence

- `App/{AppContainer,BackgroundRefreshTrigger,RefreshWakeSignal,ProviderCatalogReloadQueue}` + `Stores/{WidgetDataStore,PopoverRefreshPolicy,ProviderRefreshDeadline,RefreshSetting,RefreshOrderAllocator,MenuBarRefreshFilter}`: identity-gated startup, live quotas first then independently scheduled accounting, stale-while-revalidate and separate failure/backoff deadlines, wake coalescing without losing distinct causes, bounded provider concurrency/timeouts/cancellation; manual/enablement/catalog changes and ledger notifications take precedence without publishing a retired generation. Live cadence roughly 60 s (closed battery/low-power 120 s), live freshness 50 s; accounting 5 min open/15 min closed (5 min with sync); midnight and wake reconcile. Closed live ticks narrow to relevant/pinned providers; no disabled-provider scans; scanner pacing targets 7.5% of a core.
- `Services/{ScanWorkerClient,ScanWorkerCommand,ProcessRunner}` + `Providers/{JSONLFileReader,IncrementalJSONLScanner,JSONLScanCacheStore,AppendOnlyFileTailCache,LogUsageAggregateCache,ProcessMemoryBudget,FutureTimestampRevisionGate}`: short-lived self-executable worker for folds only, bounded JSON/stdout and deadlines, account/epoch fencing, release memory after scans; append checkpoints, oversized/incomplete tails, mutation/truncation/corruption, retained last-good, same-file dedup and per-provider cache invalidation. Native Rust does selected Claude/Codex lines and compact catalog decoding only; rest is Swift (see plan).
- `Stores/{UserDefaultsBacked,LayoutBootstrap,LayoutPersistence,LayoutStore,ProviderEnablementStore,ProviderAccountsStore,CodexAccountRegistrationStore,ProviderSnapshotCache,PersistentStoreLock}` + `App/SettingsMigrator`: versioned settings, provider registry and choices, ordered/pinned/enabled/expanded metrics, display preferences, onboarding and panel height, account registrations/identity-scoped provider snapshots, price/scan checkpoints, and stale-generation write fencing across CLI/app/worker. Undo and transient reveal are not persisted. See [refresh/cache details](../refreshing.md).
- `Services/{ShellEnvironmentSnapshot,LoginShellEnvironment,OverrideEnvironmentReader,ProxyConfig,HTTPClient,KeychainUserInteraction,SystemClients}`: startup prewarm/shell override precedence and proxy/redaction, silent scheduled credential reads, explicit refresh permits at most one auth dialog across providers, canceled loads cannot publish stale results or fall back to other accounts; atomic owner-only credential writes.
- `Services/VMBoxUsageHistory` + `Models/UsageHistoryDocument`: import `~/.local/share/vmbox/usage/vmbox-*.json` every 30 s, newest whole receipt by device, validate and retain prior good on failure, warn after five minutes; match Claude/Codex identities, exclude account-wide data, never inflate live balances or feed imported data back into machine-local exports. SSH pull is in VM Box, not QuotaBar. [Receipt contract](../vmbox-usage.md).
- `Pricing/{ModelPricing,ModelPricingStore,ModelPricingStore+Discovery,ModelRates,PricingCatalog,PricingCatalogCodecs,PricingSupplement,GatewaySlug}`: curated upstream supplement and bundle, unauthenticated public OpenRouter exact route/unique bare ID, then LiteLLM exact/fast/fuzzy and models.dev exact. Timestamped compact caches, bundled offline snapshots, tombstones/retirements, on-miss discovery/backfill; no log/model names sent in fetches. Preserve scoped aliases, cache/input/output, long-context/service-tier/UTC schedules, costs recorded by provider, explicit verified free, unpriced partials, integer overflow, and Swift-primary decimal rounding/Rust fallback. [Pricing](../pricing.md), [Rust ABI](../rust-core.md).
