# Providers and data sources

This is the catalog at the [reference revision](FEATURES.md); source names in the last column are under [`Sources/QuotaBar/Providers`](../../Sources/QuotaBar/Providers). Keep every `widgetDescriptors` ID/order and the four default flags (enabled, visible/On Demand, pinned, order) from `Stores/DefaultLayout.swift` and `Providers/ProviderCatalog.swift` as an exported fixture. Distinguish plan-dependent suppression from user-disabled metrics and explicit No data rows.

**Windows paths are discovery candidates, not proof that a Windows tool produces that profile or grants read access.** `H` = `%USERPROFILE%`, `R` = `%APPDATA%`, `L` = `%LOCALAPPDATA%`. Resolve overrides first where the original adapter does; prefer a supported vendor API/CLI or current-user documented credential store. Validate with actual Windows vendor installations and opt-in test logins before marking a row complete. Never assume that a macOS Keychain label also names a Windows credential or that a Chromium-backed app uses the same credential access mechanism.
